# Premier prompt de cadrage

Inspecte entièrement ce repository avant toute modification.

Lis `AGENTS.md`, les documents pertinents de `docs/` et les quatre portes de `docs/Forme recommandée/Ordre idéal de préparation.md`.

Ne code rien pour l'instant.

Je veux que tu :
1. reformules ce que nous construisons ;
2. identifies les décisions verrouillées ;
3. identifies les décisions encore ouvertes ;
4. détectes les contradictions, informations manquantes ou risques importants ;
5. proposes l'architecture technique appropriée ;
6. proposes un ordre d'implémentation par étapes ;
7. définisses la première vertical slice suffisamment petite pour être validée indépendamment ;
8. évalues séparément les quatre portes avec un résultat `VALIDÉE` ou `BLOQUÉE`, les preuves, les `UNKNOWN` bloquants, les `UNKNOWN` non bloquants et la prochaine action.

Ne change aucun fichier, n'installe aucune dépendance et ne commence pas l'implémentation. Une porte 4 validée exige mon accord explicite ; ne déduis jamais cet accord du simple fait que le cadrage est complet.
